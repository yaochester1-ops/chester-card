# 🍅 番茄钟 · Debug 挑战版

> 这是一个**坏掉的番茄钟**。它能打开，但藏了 **3 个 bug**。
> 你的任务：把它们一个个修好——但不是自己埋头改代码，而是**学会把问题"说清楚"给 Claude Code，让它帮你修**。

## 先搞清楚：正常的番茄钟该是什么样

修 bug 之前，你得先知道"对"长什么样。一个正常的番茄钟应该：

- ⏱️ **计时准确**：点"开始"后，每过 1 秒，时间正好少 1 秒（25:00 → 24:59 → 24:58…）
- 🔘 **按钮状态对**：没开始时按钮写"开始"；正在走时写"暂停"；点一下能在两者间切换
- 🔄 **重置能用**：任何时候点"重置"，时间都回到 25:00 并停下来
- ✅ **完成会记录**：一个番茄走完，会记进"今日完成"，刷新页面还在
- 🔒 **专注时锁任务**：开始后，上面的任务输入框不能再改

把你看到的行为和上面对比——**对不上的地方，就是 bug**。
（提示：上面 5 条里，不是每一条都坏了；坏的只有 3 处，别被没坏的那几条带偏。）

## 你的任务

找出并修好 **3 个 bug**。三个藏在不同的地方，有的一眼能看出，有的要多点几下才会冒出来。

⚠️ 别自己猜着改代码。这节课练的是 **Debug 三步法**——把问题描述清楚，让 Claude Code 定位 + 修复。

## 怎么跟 Claude Code 说：Debug 三步法

每发现一个 bug，按这三点描述给它（第 2 点可选）：

1. **描述现象**（必填）：用自己的话说"我看见了什么"
2. **贴报错**（可选）：按 `F12` 打开控制台（Console），如果有**红色报错**，把原文**复制粘贴**过去——别只发截图
3. **什么时候发生**（必填）：说清"我做了什么之后才出现的"

### 一个填好的例子（这是别的项目的，只是给你看格式）

> **现象**：转盘指针停在"一等奖"上，弹窗却说我中了"谢谢参与"。
> **报错**：F12 看了，没有红字。
> **范围**：第一次抽是对的，从第二次开始就错位了。

→ 把这样三句话发给 CC，它就能精准定位。修好一个，再找下一个。

> 💡 **不是每个 bug 都有报错**。有的 bug 在 F12 里干干净净——这时候第 2 点就写"没有报错"，**把现象和触发时机说清楚更重要**。这 3 个 bug 里，只有 1 个会在 F12 里看到红字。
